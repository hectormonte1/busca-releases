# busca-releases
Descargas y actualizaciones de Busca para macOS

## Instalar

1. Descarga [Busca.dmg](https://github.com/hectormonte1/busca-releases/releases/latest/download/Busca.dmg) (la versión más reciente).
2. Ábrelo y arrastra Busca a Aplicaciones.
3. Abre Busca desde Aplicaciones.

Busca está firmada y notarizada por Apple, así que macOS la abre sin avisos de seguridad.
Requiere macOS 15 o posterior en una Mac con Apple Silicon. Las actualizaciones llegan solas
desde el menú de Busca.
